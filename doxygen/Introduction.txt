 @mainpage Introduction
 
 @section Intro Description
 
OCILIB is an open-source, cross-platform library offering the most complete and advanced Oracle database drivers for C and C++.

Built on Oracle Call Interface (OCI), it combines broad feature coverage with fast, reliable database access and a consistent programming experience.

Use its modern C and C++ APIs to build applications ranging from everyday SQL clients to systems that rely on Oracle's advanced data and availability features.

OCILIB supports MBCS applications on all platforms and wide (UTF-16) applications on Windows, adapts to the Oracle client available at runtime, and runs across major platforms.

 @section Version Version information
 
 Current version: <b>5.0.0</b>
 
 @section Features Main features

Core:

 - Cross-platform C API (ISO C11), with 32-bit and 64-bit support
 - Modern C++ API (C++17), header-only, with iterators usable with standard algorithms
 - MBCS builds on all platforms (UTF-8 or ANSI via NLS_LANG); wide UTF-16 builds on Windows
 - Automatic adaptation to the runtime Oracle client version
 - Runtime loading of Oracle client libraries
 - SQL and PL/SQL, including blocks, cursors, index-by tables, and nested tables
 - Connections, sessions, transactions, and connection pooling
 - Statement execution, binding, fetching, bulk operations, and DML returning
 - Oracle types: scalars, dates, timestamps, intervals, LOBs, LONGs, RAWs, ROWIDs, cursors, objects, REFs, and collections
 - Error handling, Oracle warnings, optional logging, and diagnostic statistics
 - SQL and Object APIs, schema description, multiple-client environments, and hash tables
 - Transparent Application Failover (TAF) and high availability
 - Oracle Direct Path loading

Advanced (minimum Oracle release noted):

 - Scrollable statements and result sets (9i)
 - Advanced Queuing - AQ (9i)
 - Statement caching (9.2)
 - Database Change Notification / Continuous Query Notification (10.2)
 - Remote database startup and shutdown (10.2)
 - Oracle Sharding, including sharded connections and session pools (12.2)
 - Oracle SODA - Simple Oracle Document Access (18c)
 - Oracle JSON data type support, including DOM and serialized JSON operations (21c)
 - Oracle VECTOR data type support (23ai)

Feature availability also depends on the Oracle client version used by the application.
