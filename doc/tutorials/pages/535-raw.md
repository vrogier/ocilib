# RAW data

**Objectives** — by the end of this page you will be able to:

- fetch and bind `RAW` columns
- handle `ocilib::Raw` (a `std::vector<unsigned char>`)
- know when RAW vs BLOB vs LONG RAW applies

## Concepts

`RAW` = small binary (≤ 2000 bytes in-table, 32767 in PL/SQL/SQL on modern versions).

It's not a stream like a LOB — just bytes in a buffer, fetched through a raw getter into your array:

:::sample
```c
unsigned char buf[256];
OCI_UInt32   len = sizeof(buf);

OCI_Immediate(cn, OTEXT("select hextoraw('DEADBEEF') from dual"),
              OCI_ARG_RAW, buf, &len);
printf("got %u bytes: %02X%02X…\n", len, buf[0], buf[1]);
```

```cpp
Raw buf;
st.Execute("select hextoraw('DEADBEEF') from dual");
if (st.GetResultset().Next())
{
    buf = st.GetResultset().Get<Raw>(1);        /* std::vector<unsigned char> */
}
```
:::

In a resultset: `OCI_GetRaw(rs, i, buf, &len)` — pass buffer + capacity, get back
bytes written.

## Binding

:::sample
```c
unsigned char key[16] = { /* … */ };
OCI_BindRaw(st, OTEXT(":k"), key, sizeof(key));
```

```cpp
Raw key{ /* … */ };
st.Bind(":k", key);
```
:::

## C++ — `ocilib::Raw`

`ocilib::Raw` is `std::vector<unsigned char>`; getters **fill it** (v5 avoids the
temp-copy):

```cpp
Raw blob = rs.Get<Raw>(1);
st.Bind(":k", blob, BindInfo::In);
```

## When to use what

| SQL type | Size | How to access |
|----------|------|---------------|
| `RAW` | ≤ 32 KB | `OCI_GetRaw`/`OCI_BindRaw` — simple buffer |
| `LONG RAW` | huge legacy | `OCI_Long` piecewise (page 285) |
| `BLOB` | huge | `OCI_Lob` streaming (page 550) |

## Try it yourself

1. Store a 16-byte UUID in a `RAW(16)` column and read it back.
2. Fetch `sys_guid()` — a RAW — and hex-print it.
3. Compare `OCI_GetRaw` buffer-size failure when the column is longer than your array.

## Common pitfalls

- **Buffer too small** — `GetRaw` needs capacity ≥ data; check `OCI_GetDataSize` first.
- **Treating RAW as string** — it's not NUL-terminated or printable; hex-dump it.
- **RAW in PL/SQL OUT binds** — same `OCI_BindRaw` + buffer rule.

## Recap

- RAW = fixed small binary; bind/get via byte buffers; `ocilib::Raw` in C++.
